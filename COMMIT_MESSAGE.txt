Precache js/figure_details.js so the Details dialogs work offline

Every page imports js/figure_details.js -- it is what turns a figure's
explanation into a dialog behind a Details button, and what owns the single
.plot-tools row the PNG download shares. It was never added to the service
worker's SHELL list, so it was the one module in the import graph that an
offline first visit had to fetch from a network that was not there. The
dialogs failed to load, and because the import is at module top level the
failure took the rest of the page's script with it.

Adding it to SHELL, and bumping CACHE v11 -> v12 so a returning reader
refetches the shell rather than keeping a list that does not name it.

No behaviour change online. All 12 suites and the integrity check pass;
22 assets, 7.04 MB gzipped.
