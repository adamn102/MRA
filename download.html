The model bundle

The fitted model as a single JSON file — every type coefficient, every context delta, all 13 G→A intercepts and all six position splines, as coefficients and pre-evaluated per position. This is what the sequence tool runs on, and it is enough to reproduce every rate in the nucleotide table.
